## 提交信息中文乱码修复（v2.10.30, 22762a7）

### 根因（重要坑）
- 本机 PowerShell `$OutputEncoding` 非 UTF-8；**`write_to_file` 工具写入的中文 `.txt` 实际为 GBK 编码**。之前 `git commit -m "中文"` 经 shell 传入即损坏（GitHub 显示 `淇` 类乱码）。
- `git log --pretty=%B` 在 PS 下显示乱码也可能是终端解码问题，需用 `git cat-file -p HEAD | node` 读原始字节确认真实存储。

### 修复做法（已 force push main: b129fd2 → 22762a7）
1. 用 node 脚本（`fs.writeFileSync(path, msg, {encoding:'utf8'})`）生成 UTF-8 提交信息文件 `.git-commit-msg.txt`。
2. `git commit --amend -F .git-commit-msg.txt` 从文件读取（规避 shell 编码）。
3. `git push --force origin main`。

### 防复发（已配置 git 全局）
- `git config --global i18n.commitencoding utf-8` / `i18n.logoutputencoding utf-8` / `core.quotepath false`。
- **后续代理提交中文信息统一流程**：node 脚本写 UTF-8 文件 → `git commit -F 文件` / `-m` 仍可能乱码故优先 `-F`。勿直接依赖 `write_to_file` 产出的中文文本做 git 输入。
