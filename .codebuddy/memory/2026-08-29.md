## 修复 EdgeOne CI frozen-lockfile 失败
- CI 报错 `ERR_PNPM_OUTDATED_LOCKFILE`：`pnpm-lock.yaml` 含残留死依赖 `@google/genai`（v2.10.31 清理死依赖时未同步 lockfile），与 package.json 不一致，CI 默认 frozen-lockfile 拒绝安装。
- 本地执行 `pnpm install --lockfile-only --prefer-offline` 重新生成 lockfile，移除 `@google/genai`，与 package.json 一致。验证 `pnpm install --frozen-lockfile` 的 resolution 步已通过（"Lockfile is up to date"）。
- 会话间隙用户已将应用 bump 至 **v2.10.35**（HEAD=c73fc75 之后），README(中英文)/package.json/CHANGELOG 均为 2.10.35。本次 lockfile 修复归入 v2.10.35 小节（Fix/CI），不再叠加 patch。
