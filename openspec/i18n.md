# 国际化 (i18n)

本项目使用 `next-intl` 实现多语言支持。路由采用基于 Cookie/Header 的无前缀模式，保持 URL 简洁。

## 语言文件
位于 `/app/locales/` 目录下，包含超过 20 种语言：
- `en.json` (英语 - 基准)
- `zh-cn.json` (简体中文)
- `zh-tw.json` (繁体中文)
- `ar.json` (阿拉伯语)
- `es.json` (西班牙语)
- `ru.json` (俄语)
- `fr.json` (法语)
- `de.json` (德语)
- `ja.json` (日语)
- `ko.json` (韩语)
- `pt-BR.json` (葡萄牙语)
- ... 等

## 添加或更新语言
1. 在 `/app/locales/` 下创建或修改 `{locale}.json`。
2. 确保 JSON 结构与 `en.json` 完全一致。
3. 在 `middleware.ts` 和 `i18n/request.ts` 的 `locales` 数组中注册新语言。
4. 语言切换器组件 (`LanguageSwitcher`) 会自动读取支持的语言列表。

## 路由与中间件
- **Middleware**: 拦截请求并根据用户偏好或浏览器语言设置默认 Locale。
- **Request Config**: `i18n/request.ts` 负责动态加载对应的 JSON 翻译文件。若请求了不支持的语言，将默认回退至 `en`。
