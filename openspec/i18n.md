# 国际化 (i18n)

本项目使用 `next-intl` 实现多语言支持，提供了丰富的多语言界面体验。

## 语言文件
位于 `/app/locales/` 目录下，包含以下语言文件：
- `en.json` (基准语言)
- `zh-cn.json` (简体中文)
- `zh-tw.json` (繁体中文)
- `ar.json` (阿拉伯语)
- `cs.json` (捷克语)
- `es.json` (西班牙语)
- `hi.json` (印地语)
- `id.json` (印尼语)
- `it.json` (意大利语)
- `nl.json` (荷兰语)
- `pl.json` (波兰语)
- `sv.json` (瑞典语)
- `th.json` (泰语)
- `tr.json` (土耳其语)
- `ru.json` (俄语)
- `vi.json` (越南语)

## 实现细节

### 1. 配置设置
- 在 `app/layout.tsx` 中配置 `next-intl` 提供者
- 使用 `negotiator` 自动检测用户语言偏好
- 提供默认语言回退机制

### 2. 在组件中使用

#### 函数组件中使用：
```tsx
import { useTranslations } from 'next-intl';

export default function MyComponent() {
  const t = useTranslations('ComponentName');
  return <h1>{t('title')}</h1>;
}
```

#### 页面组件中使用：
```tsx
import { useTranslations } from 'next-intl';

export default function HomePage() {
  const t = useTranslations('Home');
  return (
    <div>
      <h1>{t('title')}</h1>
      <p>{t('description')}</p>
    </div>
  );
}
```

### 3. 翻译文件结构
翻译文件采用嵌套结构，按功能模块组织：

```json
{
  "Home": {
    "title": "LLM API Sentinel",
    "description": "Real-time monitoring for LLM APIs"
  },
  "Dashboard": {
    "status": "Status",
    "latency": "Latency",
    "lastChecked": "Last Checked"
  },
  "Alerts": {
    "title": "Alerts",
    "noAlerts": "No active alerts",
    "resolve": "Resolve"
  }
}
```

## 添加新语言
1. 在 `/app/locales/` 下创建 `{lang}.json` 文件
2. 复制 `en.json` 的结构作为模板
3. 翻译所有 Key 的值
4. 在 `app/layout.tsx` 中添加新语言到支持列表

## 翻译最佳实践
1. **保持一致性**：同一概念在不同模块中使用相同的术语
2. **避免硬编码**：所有用户可见文本都应通过 `t()` 函数获取
3. **考虑文化差异**：某些表达可能在不同文化中有不同含义
4. **保持简洁**：翻译应简洁明了，避免过长的文本
5. **测试验证**：添加新语言后，确保所有页面显示正确
